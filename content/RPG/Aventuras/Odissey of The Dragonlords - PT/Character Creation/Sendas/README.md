# Sendas Épicas — Organização por Personagem

Cada personagem do grupo deve ter sua Senda Épica registrada em um arquivo separado nesta pasta. Use o arquivo de modelo para criar uma cópia por personagem e mantê-la atualizada capítulo a capítulo.

Arquivos úteis:
- [Guia de Sendas — visão geral](../../OotD%20-%20Markdown/00.02%20Lidando%20com%20as%20Sendas%20%C3%89picas.md)
- [Criação de Personagem (Thylea)](../Crica%C3%A7%C3%A3o%20de%20Personagem%20Tylea.md)
- [Sendas Épicas Adicionais](../Sendas%20%C3%89picas%20Adicionais.md)

Como usar:
1) Faça uma cópia de `TEMPLATE - Senda Épica.md` e renomeie para `Senda Épica - NOME DO PERSONAGEM.md`.
2) Preencha os ganchos iniciais e alinhe 1–2 marcos por capítulo (veja a checklist no fim do modelo).
3) Após cada sessão, registre o que mudou (pagamentos, dívidas, presságios) e a próxima batida.

Sugestão: mantenha as Sendas abertas durante os capítulos 4–7 para encaixar eventos marítimos, e programe “payoffs” maiores nos capítulos 8–12.
