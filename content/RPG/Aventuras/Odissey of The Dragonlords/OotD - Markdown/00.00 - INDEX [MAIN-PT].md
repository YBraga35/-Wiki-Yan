# Odyssey of the Dragonlords - Guia de Navegação

## 📚 Como Este Diretório Está Organizado

Este vault contém **materiais aprimorados** para a campanha Odyssey of the Dragonlords, organizados para facilitar uso em mesa por DMs profissionais.

### Sistema de Tags de Idioma

- **[EN]** - Conteúdo em inglês
- **[PT]** - Conteúdo em português brasileiro
- **[MAIN]** - Versão principal recomendada
- **[ALT]** - Versão alternativa
- **[HOOK]** - Gancho de aventura/introdução


## 🎲 Uso em Mesa

### Para Sessões Rápidas (2-3 horas)

- Use arquivos individuais por encontro
- Ignore subplots opcionais
- Foque em Epic Path moments

### Para Campanhas Longas (6+ meses)

- Leia toda a seção DMsGuide
- Use material da comunidade (! Materiais e links.md)
- Integre todos os subplots
